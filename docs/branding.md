# Branding — Conta Clara

Este documento registra a direção inicial de marca do Conta Clara.

## Nome

**Conta Clara**

## Posicionamento

Um controle financeiro simples para pessoas comuns e casais que querem parar de se perder nas contas.

## Essência da marca

O Conta Clara deve transmitir simplicidade, clareza, confiança e organização.

A marca não deve parecer um banco tradicional, uma fintech complexa ou uma ferramenta financeira difícil. A proposta é ser próxima, amigável e fácil de entender.

## Público principal

O Conta Clara é pensado para:

- pessoas comuns que querem organizar melhor o dinheiro;
- casais que desejam controlar contas juntos;
- usuários que não gostam ou não conseguem manter planilhas complexas;
- pessoas que precisam de um painel simples para receitas, despesas e contas pendentes.

## Personalidade da marca

A personalidade visual e verbal do Conta Clara deve ser:

- simples;
- limpa;
- confiável;
- amigável;
- moderna;
- leve;
- objetiva;
- acessível;
- organizada.

## O que a marca deve transmitir

A identidade do Conta Clara deve comunicar:

- clareza financeira;
- tranquilidade;
- organização;
- controle sem complicação;
- segurança;
- praticidade;
- vida financeira mais leve.

## O que a marca deve evitar

A marca deve evitar:

- aparência de banco tradicional;
- excesso de elementos financeiros complexos;
- visual muito corporativo;
- visual infantil;
- cores agressivas;
- símbolos genéricos demais;
- excesso de detalhes;
- aparência de aplicativo de investimento avançado;
- linguagem visual pesada ou intimidadora.

## Paleta inicial sugerida

### Cor principal

Verde esmeralda, representando equilíbrio, confiança, saúde financeira e crescimento.

Exemplo:

```txt
#34d399
#10b981
#6ee7b7
```

### Cores de apoio

Tons escuros e neutros para transmitir organização e contraste.

Exemplo:

```txt
#030712
#09090b
#18181b
#27272a
#a1a1aa
```

### Cores funcionais

Receitas:

```txt
Verde / esmeralda
```

Despesas:

```txt
Vermelho suave
```

Pendências/atenção:

```txt
Amarelo suave
```

## Estilo visual desejado

O estilo visual deve ser:

- minimalista;
- moderno;
- digital;
- limpo;
- com boa legibilidade;
- com poucos elementos;
- com aparência de produto SaaS simples;
- adequado para web app financeiro.

## Ideias para símbolo

Possíveis caminhos para símbolo:

- monograma com as letras `CC`;
- carteira simplificada;
- gráfico minimalista;
- check de organização;
- círculo representando ciclo financeiro;
- linha simples representando fluxo de dinheiro;
- combinação de clareza + controle;
- símbolo abstrato remetendo a equilíbrio financeiro.

## Direção para logotipo

O logotipo deve ter:

- versão horizontal com símbolo + nome `Conta Clara`;
- versão apenas símbolo para favicon/app;
- boa leitura em fundo escuro;
- boa leitura em fundo claro;
- aparência simples e profissional;
- formas arredondadas e amigáveis;
- pouca complexidade visual.

## Tom de comunicação

O tom do Conta Clara deve ser:

- direto;
- simples;
- encorajador;
- próximo;
- sem linguagem técnica pesada;
- sem termos financeiros complicados quando não forem necessários.

## Frases de apoio

Possíveis frases de comunicação:

- Organize suas contas sem complicação.
- Clareza para o seu mês financeiro.
- Seu dinheiro mais fácil de entender.
- Controle financeiro simples para o dia a dia.
- Menos confusão, mais clareza nas contas.

## Princípios de produto

O Conta Clara deve sempre seguir estes princípios:

- simples;
- limpo;
- confiável;
- fácil de usar.

## Observação

Esta direção de marca é inicial e poderá evoluir conforme o produto for testado com usuários reais.
