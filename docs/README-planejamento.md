# Conta Clara

Controle financeiro simples para pessoas comuns e casais que querem parar de se perder nas contas.

## Sobre o projeto

O **Conta Clara** é uma aplicação web de controle financeiro pessoal criada para ajudar pessoas comuns, casais e famílias pequenas a organizarem melhor suas contas, cartão de crédito, assinaturas, gastos do mês e metas financeiras.

A proposta do projeto é ser simples, limpo, confiável e fácil de usar.

Este projeto é a V2 profissional do antigo **Painel Financeiro**, que nasceu como um MVP desenvolvido com HTML, CSS, JavaScript, Supabase e LocalStorage.

Agora, o Conta Clara será reconstruído com uma stack mais moderna, com foco em aprendizado, portfólio, produto real e possibilidade futura de se tornar um SaaS.

## Frase principal

> Um controle financeiro simples para pessoas comuns e casais que querem parar de se perder nas contas.

## Proposta

O Conta Clara ajuda o usuário a entender de forma simples:

* quanto entrou no mês;
* quanto saiu;
* quanto ainda falta pagar;
* quanto está no cartão;
* quais assinaturas estão ativas;
* quais contas vencem em breve;
* se o mês está positivo ou negativo;
* como estão suas metas financeiras.

A ideia não é criar um sistema financeiro complexo, mas sim uma ferramenta clara, prática e confiável para o dia a dia.

## Público-alvo

O público inicial do Conta Clara será formado por:

* pessoas comuns que querem organizar as contas;
* casais que querem acompanhar melhor os gastos;
* famílias pequenas;
* clientes que já fazem serviços com Eraldo Albano;
* pessoas que não gostam de planilhas;
* pessoas que se perdem com cartão, contas fixas e assinaturas.

## Modelo comercial inicial

O modelo inicial será:

* 30 dias grátis;
* plano mensal de R$ 14,90;
* plano anual de R$ 129,00;
* cobrança manual no início;
* ativação manual de acesso pelo administrador.

A cobrança automática ficará para versões futuras.

## Stack planejada

A V2 será desenvolvida com:

* Next.js;
* TypeScript;
* Tailwind CSS;
* Supabase;
* PostgreSQL;
* Row Level Security;
* React Hook Form;
* Zod;
* Recharts;
