# Prompt para Logo — Conta Clara

## Prompt principal

Crie uma logo profissional, moderna e minimalista para uma aplicação web chamada **Conta Clara**.

O Conta Clara é um controle financeiro simples para pessoas comuns e casais que querem parar de se perder nas contas.

A marca deve transmitir:

- simplicidade;
- clareza;
- organização;
- confiança;
- tranquilidade;
- controle financeiro sem complicação.

O estilo deve ser limpo, moderno, amigável e adequado para um produto SaaS financeiro simples.

A logo não deve parecer um banco tradicional, uma fintech complexa ou uma ferramenta de investimentos avançada. Ela deve parecer acessível, leve e fácil de usar.

Use preferencialmente uma paleta com verde esmeralda como cor principal, combinada com tons neutros escuros ou claros.

Sugestões de cores:

- verde esmeralda;
- verde suave;
- branco;
- cinza escuro;
- preto suave.

Crie uma composição com:

- um símbolo simples;
- o nome **Conta Clara**;
- versão horizontal;
- boa leitura em fundo claro e fundo escuro;
- formas levemente arredondadas;
- aparência digital e confiável.

Ideias possíveis para o símbolo:

- monograma com as letras `CC`;
- símbolo abstrato de organização financeira;
- linha simples representando fluxo financeiro;
- carteira minimalista;
- check discreto;
- círculo representando equilíbrio;
- gráfico simples e suave.

Evite:

- excesso de detalhes;
- cifrão muito óbvio;
- aparência infantil;
- aparência de banco tradicional;
- visual genérico demais;
- ícones complexos;
- muitas cores;
- letras difíceis de ler.

A logo deve funcionar bem em:

- cabeçalho de aplicativo web;
- favicon;
- ícone de app;
- página pública;
- materiais de apresentação.

## Prompt para versão ícone

Crie uma versão apenas símbolo da logo do **Conta Clara**, mantendo o estilo minimalista, moderno e confiável.

O símbolo deve funcionar como favicon e ícone de aplicativo.

Use uma composição simples, com boa leitura em tamanho pequeno.

Preferencialmente use o conceito de:

- monograma `CC`;
- clareza financeira;
- organização;
- equilíbrio;
- controle simples.

Use verde esmeralda como cor principal e mantenha fundo transparente ou fundo escuro elegante.

Evite detalhes pequenos demais.

## Prompt para versão fundo escuro

Crie uma versão da logo **Conta Clara** otimizada para fundo escuro.

Use verde esmeralda, branco e tons suaves para garantir contraste e boa leitura.

A logo deve manter aparência moderna, simples e confiável.

Inclua símbolo + texto.

## Prompt para versão fundo claro

Crie uma versão da logo **Conta Clara** otimizada para fundo claro.

Use verde esmeralda e tons escuros para garantir boa leitura.

A logo deve manter aparência moderna, simples e confiável.

Inclua símbolo + texto.

## Prompt para variações

Gere 4 variações diferentes de logo para **Conta Clara**, mantendo os princípios:

- simples;
- limpo;
- confiável;
- fácil de usar;
- moderno;
- amigável;
- financeiro sem parecer complicado.

Cada variação deve ter símbolo + texto, com estilos levemente diferentes:

1. monograma `CC`;
2. símbolo abstrato de clareza financeira;
3. ícone minimalista de organização;
4. símbolo com ideia de equilíbrio financeiro.

Todas devem usar uma paleta baseada em verde esmeralda e tons neutros.
