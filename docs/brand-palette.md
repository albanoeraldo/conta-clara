# Paleta Oficial — Conta Clara

Este documento define a paleta visual da nova identidade do Conta Clara.

## Direção visual

O Conta Clara seguirá uma identidade clara, leve, amigável e confiável.

A interface será baseada em:

- fundo claro;
- azul como cor principal;
- tons suaves de apoio;
- pouco uso de sombra;
- cards brancos;
- bordas leves;
- textos em azul-marinho/grafite;
- ilustrações em tons de azul.

## Cores principais

### Azul principal

Usado em botões principais, destaques, links importantes e elementos de marca.
