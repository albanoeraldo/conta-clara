# Conta Clara v0.2.0

## Visão geral

A versão v0.2.0 marca a nova fase visual do Conta Clara.

Nesta versão, o projeto recebeu uma revisão completa de identidade visual, incluindo página pública, autenticação, onboarding, dashboard, telas internas, componentes base, estados vazios, microinterações, sidebar e formulários.

O objetivo principal foi transformar o Conta Clara em um produto com aparência mais própria, clara, simples e confiável.

## Principais entregas

- Página pública inicial repaginada
- Direção visual clara definida
- Telas de login e cadastro repaginadas
- Onboarding visual melhorado
- Dashboard principal repaginado
- Layout interno atualizado com sidebar lateral
- Sidebar ajustada para azul-marinho
- Componentes base refinados
- Estados vazios melhorados com mais personalidade
- Microinterações e transições leves adicionadas
- Consistência visual global revisada
- Tela de lançamentos atualizada para o padrão claro
- Tela de novo lançamento atualizada para o padrão claro
- Tela de editar lançamento atualizada para o padrão claro
- Tela de categorias atualizada para o padrão claro
- Tela de perfil atualizada para o padrão claro
- Tela de configurações atualizada para o padrão claro
- Ícones automáticos aplicados em categorias
- Ícones automáticos aplicados em lançamentos
- Ícones automáticos aplicados no dashboard
- Logo, favicon e identidade visual aplicados
- Formulários internos padronizados
- Inputs, selects e textareas padronizados
- Blocos escuros remanescentes removidos das telas principais

A versão v0.2.0 consolida o Conta Clara como um produto visualmente mais maduro, com identidade própria e experiência mais consistente.
