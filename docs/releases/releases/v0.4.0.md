# v0.4.0 — Relatórios e inteligência financeira simples

A versão `v0.4.0` consolida a área de relatórios do Conta Clara, trazendo uma visão mais clara do mês financeiro e ajudando o usuário a entender melhor seus gastos, comparações e evolução recente.

Esta versão mantém a proposta principal do produto:

> Um controle financeiro simples para pessoas comuns e casais que querem parar de se perder nas contas.

## Principais entregas

### Relatório mensal por categoria

Foi criada a tela `/relatorios`, permitindo visualizar os gastos do mês agrupados por categoria.

A funcionalidade inclui:

- total de despesas do mês;
- quantidade de categorias com gasto;
- maior categoria de gasto;
- ranking de categorias;
- percentual de cada categoria sobre o total de despesas;
- gráfico simples de barras horizontais;
- integração com o mês de referência global.

### Maiores despesas do mês

Foi adicionada uma seção para exibir os maiores gastos individuais do mês selecionado.

A funcionalidade considera apenas despesas válidas e ignora lançamentos cancelados.

São exibidos:

- descrição da despesa;
- categoria;
- data;
- status;
- valor;
- ranking das maiores despesas.

### Resumo inteligente do mês

Foi criado um resumo textual simples do mês financeiro.

O resumo mostra:

- total de receitas;
- total de despesas;
- saldo previsto;
- maior categoria de gasto;
- maior despesa individual.

A linguagem foi pensada para ser clara e útil para pessoas comuns, sem termos financeiros complexos.

### Fechamento mensal com resumo salvo

Foi criada a funcionalidade de fechamento mensal.

Agora o usuário pode fechar o mês selecionado e salvar um resumo financeiro daquele período.

O fechamento salva:

- mês de referência;
- total de receitas;
- total de despesas;
- saldo final;
- maior categoria de gasto;
- maior despesa individual;
- data e hora do fechamento.

Também foi adicionada a possibilidade de reabrir o mês.

Nesta primeira versão, o fechamento é informativo e ainda não bloqueia alterações nas demais telas.

### Comparação com o mês anterior

Foi adicionada uma comparação entre o mês selecionado e o mês anterior.

A tela mostra:

- diferença de receitas;
- diferença de despesas;
- saldo acumulado dos dois meses;
- mensagens simples para interpretar o resultado.

### Evolução dos últimos 6 meses

Foi criada uma visão dos últimos 6 meses, usando o mês selecionado como referência final.

Para cada mês são exibidos:

- receitas;
- despesas;
- saldo;
- barra visual simples de despesas;
- destaque visual para saldo positivo ou negativo.

## Banco de dados

Foi criada a tabela:

- `monthly_closings`

Essa tabela armazena os fechamentos mensais do usuário.
