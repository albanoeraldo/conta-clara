# Release v0.1.0 — Primeira versão funcional

Esta release marca a primeira versão funcional do Conta Clara.

## Resumo

O Conta Clara chegou à versão `v0.1.0` com um fluxo funcional completo para controle financeiro simples.

Nesta versão, o usuário já consegue:

- criar conta;
- fazer login;
- concluir onboarding;
- acessar área interna protegida;
- cadastrar receitas e despesas;
- organizar lançamentos por categoria;
- visualizar dashboard com resumo mensal;
- acompanhar próximas contas;
- visualizar gráfico de receitas x despesas;
- editar lançamentos;
- marcar lançamentos como pagos;
- cancelar lançamentos;
- gerenciar categorias;
- editar perfil;
- editar configurações do espaço financeiro.

## Principais entregas

### Autenticação

- Cadastro
- Login
- Logout
- Proteção de rotas
- Redirecionamentos de acesso

### Banco de dados

- Integração com Supabase
- Uso de PostgreSQL
- Tabelas principais:
  - `profiles`
  - `financial_spaces`
  - `categories`
  - `transactions`

### Segurança

- RLS configurado
- Dados vinculados ao usuário autenticado
- Dados financeiros isolados por `financial_space`
- Atualizações filtradas por espaço financeiro

### Produto

- Onboarding inicial
- Dashboard mensal
- Lançamentos financeiros
- Categorias
- Perfil
- Configurações

### Interface

- Layout interno
- Componentes reutilizáveis
- Gráfico com Recharts
- Botões e seções padronizadas
- Identidade visual inicial

### Documentação

- README
- Status do projeto
- Roadmap
- Changelog
