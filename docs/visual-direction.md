# Direção Visual — Conta Clara v0.2.0

Este documento define a direção visual da nova fase do Conta Clara.

## Objetivo da nova fase

A versão `v0.2.0` tem como objetivo evoluir o Conta Clara de uma aplicação funcional para um produto com identidade visual mais própria, mais vivo e menos genérico.

A proposta é manter a simplicidade e a confiança, mas adicionar mais personalidade, cor, imagens, interações e detalhes visuais.

## Decisão principal

A partir desta fase, o Conta Clara será pensado como um produto **light-first**.

Isso significa que a interface principal será clara, com fundo branco ou off-white, cards claros, textos em grafite e azul como cor principal.

O modo escuro poderá ser implementado futuramente como opção para o usuário, mas não será o foco principal desta fase.

## Por que light-first?

O tema claro combina melhor com o nome **Conta Clara**.

A interface clara deve transmitir:

- clareza;
- simplicidade;
- organização;
- leveza;
- confiança;
- facilidade;
- uso diário;
- menos sensação de sistema pesado.

O objetivo é sair da aparência de dashboard escuro genérico e aproximar o produto de uma ferramenta financeira simples, acessível e agradável.

## Princípios visuais

O Conta Clara deve continuar sendo:

- simples;
- limpo;
- confiável;
- fácil de usar;
- organizado;
- amigável;
- moderno.

Nesta nova fase, também deve parecer:

- mais vivo;
- mais claro;
- mais leve;
- menos genérico;
- mais próximo de um produto real;
- mais visual;
- mais acolhedor.

## Direção geral

O visual deve fugir da aparência padrão de template escuro genérico.

A interface deve transmitir:

- clareza;
- calma;
- segurança;
- controle;
- organização;
- praticidade;
- leveza.

O Conta Clara não deve parecer:

- banco tradicional;
- aplicativo financeiro complexo;
- sistema corporativo frio;
- template genérico de IA;
- app infantil;
- dashboard pesado demais.

## Paleta principal

A nova fase usará azul como cor principal.

### Azul principal

Usado em botões principais, destaques, links importantes e elementos de marca.

Sugestões:

```txt

#3b82f6
#60a5fa
```

Usado para textos fortes, detalhes premium, áreas de destaque e contraste.

Usado em detalhes, brilhos, hover, cards de apoio e elementos visuais leves.

## Estilo dos cards

Os cards devem ter:

- fundo claro;
- bordas suaves;
- cantos arredondados;
- sombra leve;
- contraste bem definido;
- boa leitura;
- aparência limpa;
- detalhes em azul quando necessário.

Evitar:

- cards todos iguais;
- excesso de borda;
- sombras exageradas;
- transparência demais;
- visual pesado;
- aparência de dashboard escuro genérico.

## Estilo dos botões

Os botões devem ser:

- claros;
- fáceis de tocar;
- com hover perceptível;
- com transição suave;
- visualmente mais vivos.

### Botão principal

- azul forte;
- texto branco;
- bom contraste;
- leve sombra;
- aparência moderna.

### Botão secundário

- fundo branco ou azul muito claro;
- borda suave;
- texto azul ou grafite;
- hover com contraste leve.

### Botão de perigo

- vermelho suave;
- sem exagero visual;
- claro e objetivo.

## Estilo dos ícones

Os ícones devem:

- usar `lucide-react`;
- ser simples;
- ter tamanho confortável;
- evitar excesso de círculos e molduras;
- aparecer com cor e hover quando forem ações.

Ícones de ação devem ser diretos:

- editar;
- cancelar;
- salvar;
- pagar;
- reativar;
- configurar.

## Estilo das imagens e ilustrações

A nova fase pode usar imagens, ilustrações ou mockups, mas com cuidado.

O estilo ideal:

- moderno;
- limpo;
- flat ou semi-flat;
- SaaS;
- financeiro leve;
- amigável;
- profissional;
- com predominância de azul, branco e tons suaves.

Evitar:

- ilustrações infantis;
- mascote como identidade principal nesta fase;
- excesso de personagens;
- imagens genéricas demais;
- gráficos falsos poluídos;
- muitos elementos decorativos sem função.

## Mascote

A ideia de mascote, como um gato, ficará guardada para o futuro.

Nesta fase, o foco será:

- identidade clara;
- visual light-first;
- azul como cor principal;
- interface mais viva;
- imagens e mockups;
- mais personalidade sem infantilizar o produto.

O mascote poderá ser reconsiderado futuramente para:

- estados vazios;
- onboarding;
- mensagens amigáveis;
- materiais de apoio.

## Gradientes

Gradientes podem ser usados para dar vida ao produto.

Uso recomendado:

- fundos suaves;
- hero da página pública;
- detalhes de cards;
- brilhos leves;
- áreas de destaque;
- telas de autenticação.

Evitar:

- gradientes fortes demais;
- excesso de cores;
- gradiente em todos os elementos;
- aparência artificial.

## Microinterações

A nova fase deve usar microinterações leves:

- hover em cards;
- hover em botões;
- transições suaves;
- feedback visual em ações;
- animações discretas em carregamento;
- estados vazios mais amigáveis.

Evitar:

- animações longas;
- movimento excessivo;
- efeitos que atrapalhem o uso;
- perda de performance.

## Direção por tela

### Página pública

Deve ser mais visual, com mais personalidade e melhor primeira impressão.

Pode ter:

- hero mais impactante;
- fundo claro com detalhes em azul;
- mockup do app;
- imagem ou ilustração;
- blocos de benefício;
- chamada clara para cadastro.

### Login e cadastro

Devem parecer mais acolhedores e confiáveis.

Podem ter:

- área visual lateral;
- texto de apoio;
- cards brancos;
- fundo com gradiente azul muito suave;
- identidade azul mais forte.

### Onboarding

Deve explicar melhor o que o usuário está configurando.

Pode ter:

- card mais amigável;
- texto explicativo;
- melhor hierarquia;
- visual menos seco.

### Dashboard

Deve ser a tela mais forte do app.

Pode ter:

- cards claros;
- destaque melhor para saúde do mês;
- gráfico mais bonito;
- blocos com mais contraste;
- detalhes em azul;
- melhor hierarquia visual.

### Lançamentos

Deve continuar extremamente funcional, mas pode ficar mais elegante.

Pode ter:

- filtros mais bonitos;
- lista com melhor separação visual;
- ações mais claras;
- estados vazios melhores.

### Categorias

Deve ficar mais visual e organizada.

Pode ter:

- cores por categoria;
- ícones no futuro;
- melhor agrupamento;
- ações mais suaves.

## Tom visual desejado

O Conta Clara deve parecer:

```txt
SaaS moderno + app financeiro simples + produto amigável + visual claro e confiável
```

Não deve parecer:

```txt
template genérico + banco tradicional + dashboard pesado + app infantil
```

## Decisão desta fase

Nesta fase, a logo definitiva ainda não será aplicada.

A identidade visual será melhorada primeiro na interface, usando:

- fundo claro como padrão;
- azul como cor principal;
- componentes mais refinados;
- telas públicas mais marcantes;
- dashboard mais visual;
- microinterações leves.

A logo definitiva e o modo escuro ficarão para etapas futuras.
