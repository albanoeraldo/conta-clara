# Roadmap — Conta Clara

Este documento registra ideias e próximas etapas planejadas para evolução do Conta Clara.

## Objetivo do roadmap

Organizar as próximas melhorias do projeto, mantendo clareza sobre o que já foi entregue e o que ainda pode ser evoluído.

## Fase atual

O projeto está na primeira versão funcional em desenvolvimento.

As principais funcionalidades já foram implementadas:

- autenticação;
- onboarding;
- dashboard;
- lançamentos;
- categorias;
- perfil;
- configurações;
- gráfico de receitas x despesas;
- identidade visual inicial;
- documentação base.

## Próximas melhorias planejadas

### 1. Melhorias visuais

- Criar logotipo definitivo.
- Melhorar paleta de cores.
- Adicionar ícones no menu.
- Adicionar ícones nos botões de ação.
- Melhorar telas vazias.
- Melhorar feedback visual de carregamento.
- Melhorar responsividade mobile.
- Revisar espaçamentos em telas pequenas.

### 2. Melhorias em lançamentos

- Criar visual de detalhes do lançamento.
- Melhorar filtros de lançamentos.
- Adicionar busca por descrição.
- Adicionar filtro por categoria.
- Adicionar filtro por forma de pagamento.
- Permitir duplicar lançamento.
- Permitir criar lançamentos recorrentes.
- Melhorar controle de status.
- Avaliar exclusão definitiva com confirmação.

### 3. Melhorias em categorias

- Adicionar ícones visuais por categoria.
- Permitir escolher cor da categoria.
- Permitir escolher ícone da categoria.
- Melhorar edição de categorias.
- Exibir quantidade de lançamentos por categoria.
- Criar relatório por categoria.

### 4. Melhorias no dashboard

- Exibir evolução mensal.
- Criar gráfico por categoria.
- Criar gráfico por forma de pagamento.
- Exibir resumo de despesas fixas.
- Exibir alerta de contas vencidas.
- Exibir saldo disponível estimado.
- Exibir comparação com renda mensal.

### 5. Relatórios

- Criar relatório mensal.
- Criar relatório anual.
- Exportar dados em CSV.
- Exportar resumo em PDF futuramente.
- Criar visão por período personalizado.
- Criar análise de maiores gastos.

### 6. Experiência do usuário

- Melhorar mensagens de erro.
- Melhorar mensagens de sucesso.
- Criar confirmações mais bonitas no lugar do `window.confirm`.
- Criar estados de carregamento com skeleton.
- Criar tela de boas-vindas após onboarding.
- Melhorar fluxo para primeiro lançamento.

### 7. Segurança e confiabilidade

- Revisar políticas RLS.
- Revisar permissões das tabelas.
- Melhorar tratamento de erros do Supabase.
- Criar testes manuais documentados.
- Criar testes automatizados futuramente.
- Revisar validações de formulários.

### 8. Produto e monetização

- Testar com usuários reais.
- Validar proposta de valor.
- Criar plano grátis/teste.
- Criar plano mensal.
- Criar plano anual com desconto.
- Criar página simples de apresentação.
- Criar estratégia de cobrança manual inicial.
- Avaliar integração futura com gateway de pagamento.

## Ideias para versão SaaS

Possíveis recursos futuros:

- múltiplos espaços financeiros por usuário;
- compartilhamento entre casal/família;
- convites por e-mail;
- relatórios automáticos;
- lembretes de vencimento;
- notificações por WhatsApp;
- importação de planilhas;
- integração bancária futura, se fizer sentido.

## Princípios do produto

O Conta Clara deve continuar seguindo estes princípios:

- simples;
- limpo;
- confiável;
- fácil de usar;
- amigável para pessoas comuns;
- sem complexidade desnecessária.

## Posicionamento

> Um controle financeiro simples para pessoas comuns e casais que querem parar de se perder nas contas.
